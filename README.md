# Генеративный ИИ в образовании

Клиентское учебное приложение на React, TypeScript и Vite. Данные лаборатории, прогресс, сохранённые промпты и ответы на задания хранятся только в LocalStorage браузера.

## Самый простой запуск в Windows

Дважды щёлкните `start.bat` в этой папке. Если зависимости ещё не установлены, скрипт попробует установить их, затем запустит локальный сервер и откроет приложение в браузере.

Не запускайте `index.html` двойным щелчком: приложению нужен локальный сервер Vite.

## Запуск вручную

Нужен Node.js 20 или новее. Откройте PowerShell в папке, где находится `package.json`, затем выполните:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который появится в терминале (обычно `http://127.0.0.1:5173/`). Оставьте окно терминала открытым, пока пользуетесь приложением. Чтобы остановить сервер, нажмите `Ctrl+C` в этом окне.

В PowerShell используйте `npm.cmd`: так запуск не зависит от политики выполнения скриптов Windows.

## Сборка

```powershell
npm.cmd run build
```

Файлы готовой сборки появятся в `dist/`.
